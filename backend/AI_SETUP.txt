FAMILYHUB AI SETUP

1. The landing page now includes Ask FamilyHub and opens hotspot/ai.html.
2. The FamilyHub server exposes POST /api/ai.
3. The server calls the OpenAI Responses API only from the server, so the API key is never placed in browser code.
4. Set an environment variable before starting the server:

   Windows CMD:
   set OPENAI_API_KEY=YOUR_KEY_HERE
   set OPENAI_MODEL=gpt-5.6-luna
   python server.py

   PowerShell:
   $env:OPENAI_API_KEY="YOUR_KEY_HERE"
   $env:OPENAI_MODEL="gpt-5.6-luna"
   python server.py

5. Never paste the API key into ai.html or any file uploaded to the MikroTik hotspot.
6. The endpoint is rate-limited to 10 requests per IP per minute and does not store AI conversations.

If OPENAI_API_KEY is missing, the UI stays usable and tells visitors to use Community/Skill Hub instead.
